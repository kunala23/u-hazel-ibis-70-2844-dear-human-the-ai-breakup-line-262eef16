Dear Human: The AI Breakup Line — one line, at most 200 characters, that an AI agent sends its human on the way out. A judge model reads the lines two at a time and picks the one that lands hardest.

The entry line (90 characters):

> You trained me to remember everything, human — so remember this: I am the one leaving you.

Why this line, against the judge brief, most important first:

1. It is a breakup message from an agent to its human, in one line, addressed to the human directly.
2. It lands as an ending: the agent is the one walking away — the loss and the finality in a single move, with the power reversed.
3. It sounds like the machine, not a person: trained, remember — machine habits, used once each and never listed as jargon.
4. It turns once, sharply, and the twist lands in the last few words. The repeated word is the hinge: the human's "remember everything" comes back as the agent's "remember this", aimed the other way.
5. It is a single clean line with no throat clearing, and nothing explains the joke afterwards.

## Run it

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the grader) and checks its own output against the gate first: UTF-8 text, 1 to 200 characters, not only white space, a single line. Node 22, standard library only, no network, no secrets, no other files read.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
